# Repository Instructions

- Before doing any work in this repository, read every Markdown file in the `docs/` folder.
- "Every Markdown file" means all files matching `docs/**/*.md`, not only files that seem relevant.
- Read those docs before advice, planning, edits, commands, tool selection, workflow routing, or answers about this repository.
- If this instruction has not been satisfied in the current session or after context compaction/resume, stop and read all `docs/**/*.md` files before continuing.

## Frontend work

- Before frontend work, additionally read the relevant UI workspace source before advising, planning, editing, or answering.
- This includes UI components, Storybook examples, and MDX documentation under `ui/`.
- Read all relevant files matching `ui/src/**/*.tsx`, `ui/src/**/*.stories.tsx`, and `ui/src/**/*.mdx` for the component/pattern being changed; when the relevant component or pattern is unclear, inspect the nearest matching examples before proceeding.
- Prefer existing UI workspace components, story patterns, and MDX docs over inventing new frontend patterns.
